## award-website-builder v1.0.0 — 2026-06-14

**Build Awwwards-tier brand sites in 75 minutes.**

First stable release. Distilled from two Awwwards-tier production sites — DICH Fashion (Webflow) and Hermes Desktop (Nous Research).

### What's inside

- **Design tokens** — 3 CSS files (22KB), 9 theme presets, container query unit system
- **5 zero-dep JS modules** — noise canvas, smooth scroll, text scramble, parallax, type splitter
- **12 HTML templates** — 6 hero patterns + 6 section patterns
- **9 color palettes** — each with light/dark inversion
- **6 font sets** — each with free Google Fonts alternatives
- **30+ SVG elements** — icons, decorative shapes, loaders, atmospheric
- **3 prompt libraries** — image generation, typography, color pairing
- **2 worked examples** — 60 min fashion launch + 45 min AI tool landing
- **48-point self-audit** — ship only when score ≥ 90
- **10万字+ analysis** — MASTER-ANALYSIS.md with line-numbered references
